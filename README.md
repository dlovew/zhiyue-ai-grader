# 智阅批改助手

智学网阅卷页面的油猴脚本：读取作答图，按你配置的参考答案与评分标准，调用 OpenAI 兼容的多模态模型直接评分，并把分数回填、提交。支持连续批阅、手动改分、历史导出与本地缓存。

- 版本：`1.0.3`
- 适用站点：`www.zhixue.com`、`zhixue.com` 及 `*.zhixue.com`
- 形态：单文件用户脚本，无后端；所有配置与记录只存在浏览器本地

## 功能特性

- **多模态直评**：只走一条链路，把作答图直接交给视觉模型评分，不做 OCR 中转。
- **评分标准生成**：覆盖语数英物化生史政地九科，按题型生成结构化标准；支持文字/图片输入，可从生成结果一键填入题目、参考答案、标准与满分。
- **多平台**：内置 DeepSeek、硅基流动、Kimi、通义千问、智谱、火山方舟、商汤日日新等预设，也可自定义任意 OpenAI 兼容接口。
- **按平台记忆**：API Key、模型、思考模式分平台保存，切换平台自动恢复，不串号。
- **手动改分**：总分与小题分可直接编辑，提交用改后分数，并同步写回缓存。
- **连续批阅**：自动「批改 → 提交 → 等换卷 → 继续」，出错或等不到换卷自动停止。
- **省 Token**：输出三档、紧凑 JSON 协议、`max_tokens` 上限；图片只做等比缩小（绝不放大），精度可选，选了学科按学科套用长边上限。
- **用量可见**：每份结果显示输入/前缀命中/输出/思考 token；历史面板按当前筛选汇总；CSV/HTML 导出带用量列与汇总行。
- **本地缓存**：同题同图命中即跳过下载与请求；双评第二遍几乎零等待、零 token。

## 安装

1. 安装 Tampermonkey 或 Violentmonkey。
2. 获取脚本：下载本仓库 `dist/智阅批改助手.user.js`，或用源码构建（见「开发」）。
3. 把脚本文件拖入浏览器窗口，或在脚本管理器中新建脚本并粘贴内容。
4. 打开智学网阅卷页面，面板自动挂载；也可从油猴菜单打开面板、设置、历史。

> 脚本管理器若要求跨域权限，请放行 `@connect *`，否则无法调用你配置的模型接口。

## 快速开始

1. 打开阅卷页面，等面板提示「已读取题号 xx」。
2. 进 **设置**：
   - **批改上下文**：填参考答案、评分标准、本方案满分（题目建议填，或用「评分标准生成」一键填入）。
   - **接口与链路**：选平台，填 API Key 与模型名，点「测试多模态」验证连通。
3. 保存后回到面板，点 **开始批改**。
4. 需要修正时直接改分，再点 **提交结果**。

## 使用说明

### 面板按钮

| 按钮 | 作用 |
| --- | --- |
| **开始批改** | 读取当前题作答图并评分，结果写入历史。 |
| **连续批阅** | 循环「批改 → 提交 → 等换卷」；开始前二次确认，运行中再点可停止。 |
| **提交结果** | 把分数写入智学网打分框并提交；勾选「一次提交（免确认）」后跳过确认框。 |
| **历史** | 查看记录，支持筛选、导出 CSV/HTML、清空。 |
| **设置** | 打开配置面板。 |

### 设置面板

分四个标签页：

1. **批改上下文**：题目、参考答案、评分标准、满分。后三项必填，满分需与实际一致；题目留空会降低判断精度。
2. **接口与链路**：平台预设、接口地址、API Key、模型名、思考模式。切换平台会恢复该平台此前的 Key/模型/思考模式，但不会替你填模型名；「获取模型列表」可拉取接口支持的模型。
3. **评分标准生成**：选学科与题型 → 填满分、题目、标准答案（文字或图片）→ 生成 → 在线编辑 → 一键填入。
4. **高级**：导出/导入配置、图片与提示词参数、限流与超时、累计用量、重置与清空。

### 手动改分

结果区的总分与小题分都是可编辑数字框：

- 改小题分，总分自动求和；
- 改总分，小题分按比例分摊并做尾差修正；
- 提交时使用改后分数，并把改后结果写回缓存，双评第二遍命中即为最终分。

### 连续批阅

点「连续批阅」并确认后，脚本会批改当前卷、静默提交、等列表换成下一份，再继续，直到手动停止、报错或超时未换卷。

提交后等待期间可以切标签页、最小化窗口，后台等待会暂停超时倒计时且换卷识别不依赖图片加载完成；但别离开阅卷页，页面重载会丢失连续批阅状态。连续批阅会跳过所有确认框，请确认标准无误再开启。

### 历史与导出

- 列表按「全部/需复核/正常」与关键字筛选，顶部实时汇总当前筛选结果：条数、本地命中次数与命中率、输入/前缀命中/输出/思考 token。
- 每条记录可看详情：题号、链路/模型、得分、用量、命中与耗时、依据、复核原因、小题分。
- **CSV**：带 BOM，Excel 直接打开；18 列，含模型、需复核、复核原因、是否已提交、输入/前缀命中/输出/思考 token、命中、耗时，末尾一行汇总。
- **HTML**：独立文件，顶部带汇总条，表格含模型、输入/前缀命中/输出/思考 token、命中、耗时与复核标记。
- 命中列区分「本地命中」（命中结果缓存，零 token）、「前缀命中」（服务商侧缓存命中，仍计输入）、「未命中」。

## 支持的服务平台

内置预设：`自定义`、`opencode.ai`、`DeepSeek`、`商汤日日新（SenseNova）`、`硅基流动`、`Kimi / Moonshot`、`通义千问 / DashScope`、`智谱 GLM`、`火山方舟（Chat）`。

**思考只有两档**：`关闭思考` / `模型默认`（不传强度参数），默认关闭。各平台支持的强度档位并不统一（DeepSeek 是 none/low/high/max，商汤是 minimal～max，智谱只有 low/high/max），统一暴露两档比按平台切换更好用，也不容易踩到不支持的参数。

「关闭」在各平台的实现：

| 平台 | 关闭时传参 |
|---|---|
| DeepSeek / 商汤日日新 | `reasoning_effort: "none"` |
| 硅基流动 / 通义千问 | `enable_thinking: false` |
| Kimi / 火山方舟 | `thinking.type: "disabled"` |
| 智谱 GLM | 不注入（GLM-5.3 / GLM-5.3-FLASH 强制思考，传关闭参数会报 1210） |
| 自定义 | 不注入，靠模型自身默认 |

**能不能关闭取决于模型，而不是平台**，因此有两层兜底：

- 已知强制思考的模型（`GLM-5.3`、`GLM-5.3-FLASH`）直接按「模型默认」运行，不发关闭参数，不浪费请求。
- 其它模型若返回「不支持关闭思考」，自动去掉关闭参数重试一次，并按「平台+模型」记住；下次不再试错。「测试当前思考模式是否生效」也会提示是否强制思考。

平台细节：

- **商汤日日新**：推理 `POST https://token.sensenova.cn/v1/chat/completions`，模型列表 `GET https://token.sensenova.cn/v1/models`（Bearer），默认 `sensenova-6.8-flash`；拉列表时 `input_modalities` 含 `image` 的模型排前。
- **硅基流动**：`enable_thinking` 只接受布尔值，关闭时发 `enable_thinking: false`。选「模型默认」时部分模型会生成很长的推理，72B 级模型处理图片可能超过默认 120 秒超时——可调大超时、换小模型或选「关闭」。
- 选平台只填建议的地址与协议参数，**你填的 endpoint / model / apiKey 始终优先**；必须是支持图片输入的模型，接口需兼容 `POST /chat/completions`。API Key 仅存本地（`GM_setValue`）。

## 成本与缓存

### 本地结果缓存

- 命中条件：题目、参考答案、评分标准、满分、小题、作答图 URL 列表、模型、图片参数、思考模式、输出档位全部一致。
- **先查缓存再取图**：命中时不下载图片、不做缩放、不构建提示词，双评换号几秒出结果。
- **改分回写**：提交后以改后分数更新缓存，第二遍命中拿到的是最终分而非模型原始分。
- 默认 2000 条、30 天有效；双评大卷建议提到 3000。
- 合并批量写盘（约 1.2 秒一次，关页前补写），超限按 10% 分批淘汰；配额满时提示一次并停止写入。
- 缓存里不保存模型原文，只留评分结果；命中不消耗任何 token。

### 图片 token（只受像素尺寸与精度影响，JPEG 质量不影响计费）

- 自动剔除重复图、空白图与废图（不收 token）。
- **只等比缩小，绝不放大**：按「长边上限」缩放，原图本来更小就保持原始像素。裁白边、宽条切块重排、多图合并等会改变版面或牺牲分辨率的处理已全部下线。
- 参数：长边上限 600～2400（默认 1600），JPEG 质量 0.5～1（默认 0.82），精度 `high`/`auto`/`low`。
- 精度 `low` 只适合选择、填空判对错，主观题请用 `high`；低精度或原图清晰却被缩到短边 < 320px 时，结果自动标记人工复核。
- 学科策略：选定学科后自动套用长边上限——数学/物理/化学 1600px，语文/英语/生物 1440px，历史/政治/地理 1280px，精度一律 `high`；关闭「按学科自动套用」或未选学科则完全按手动参数。

### 输出 token

- 紧凑协议：`s` 状态、`sc` 得分、`c` 置信度、`r` 评语，`sub` 用 `i` 索引代替小题名；满分与满分小题的扣分理由不再由模型回写。
- 三档（「高级」里切换）：
  - 简略：只打分与置信度，`max_tokens` 400；
  - 标准：总评语 ≤ 30 字 + 仅扣分小题 ≤ 20 字，`max_tokens` 800；
  - 详细：总评语 ≤ 60 字 + 每题 ≤ 40 字依据，`max_tokens` 1400。
- 开启思考时上限按 1.8 倍放宽，避免推理挤占导致 JSON 截断。
- 输出档位与思考模式都进缓存键，切换后不会误命中旧结果。

### 用量可见

- 每份结果下方：`输入 1234（前缀命中 900）· 输出 180（含思考 60）`，取自响应 `usage`，读取不产生额外 token 或请求；本地缓存命中显示「缓存命中」，零 token。
- 「高级」页底部累计：批改次数、本地命中次数与命中率、请求次数、累计输入/前缀命中/输出/思考 token，全为本地计数，「清空数据」时一并清除。

## 开发

模块化源码由构建脚本按固定顺序拼成单文件，零第三方依赖。

```bash
# 构建（更新 dist/智阅批改助手.user.js）
node build.mjs

# 测试
node --test tests/api-compat.test.mjs
```

- `src/`：功能源码（适配器、基础设施、核心流程、UI）
- `build.mjs`：拼接与脚本头横幅
- `dist/智阅批改助手.user.js`：可直接安装的产物
- `tests/`：接线与行为一致性测试

改源码后必须重新构建，`dist/` 才会更新。

## 注意事项

- 先在少量试卷上验证评分标准与模型效果，再用于大批量阅卷。
- 不同模型打分尺度差异较大，建议固定一个模型并配套调整标准。
- 思考是否真正关闭取决于服务端实现，可用内置测试按钮验证。
- 连续批阅会自动提交分数，请谨慎开启。
