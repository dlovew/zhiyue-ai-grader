# 智阅批改助手

一款运行在 **智学网阅卷页面** 上的油猴用户脚本。它读取试卷上的作答图片，结合你配置的参考答案与评分标准，调用 **OpenAI 兼容的多模态大模型（VLM）** 直接评分，并可将分数回填、提交，支持连续批阅、手动改分、历史记录与导出。

- 版本：`1.0.2`
- 适用站点：`www.zhixue.com`、`zhixue.com` 及任意 `*.zhixue.com` 子域
- 脚本类型：Tampermonkey / Violentmonkey 用户脚本（单文件，无需后端）

## 功能特性

- **多模态直评**：只走一条链路——把作答图直接交给视觉语言模型评分，不依赖 OCR 或文本推理。
- **评分标准生成器**：覆盖语文、数学、英语、物理、化学、生物、历史、政治、地理九大学科，按题型生成结构化评分标准；支持文字或图片输入，可手动设置满分，一键填入题目、参考答案与评分标准。
  - 按点给分题（如地理综合题、材料分析题）：只列得分点，答不到不扣分，不生成倒扣/负分规则。
  - 作文、论述题：按档次给分，给出各档分数区间与可观察特征。
- **多平台兼容**：内置 OpenAI、Azure OpenAI、DeepSeek、硅基流动、Kimi、通义千问、智谱、火山方舟等预设，也支持任意自定义 OpenAI 兼容接口；所有请求统一使用 Chat Completions。
- **按平台记忆**：API Key 与模型按平台分别保存，切换平台时自动恢复，不会串号。
- **模型列表获取**：可从接口的 `/models` 端点拉取可用模型并直接选用。
- **思考模式可切换**：下拉菜单支持「关闭 / low / high / max / 不干预」；关闭模式省 Token，智谱 glm-5 等始终思考的模型改用 low/high/max；一键测试当前模式是否生效。
- **手动改分**：批改结果的总分与每小题分数可直接编辑，提交时使用改后分数。
- **免确认提交**：勾选「一次提交（免确认）」后，手动提交不再弹出二次确认。
- **连续批阅**：自动批改并提交当前试卷，等待换卷后继续下一份，出错或等不到换卷自动停止。
- **历史与导出**：记录每次批改结果，可导出为 CSV 或 HTML。
- **本地缓存与限流**：相同题目与图片命中缓存；支持并发数、RPM、TPM 预算控制。

## 安装

1. 在浏览器安装油猴脚本管理器（Tampermonkey 或 Violentmonkey）。
2. 获取脚本文件：
   - 从本仓库 `dist/智阅批改助手.user.js` 下载，或
   - 用源码自行构建（见「开发」）。
3. 将 `智阅批改助手.user.js` 拖入浏览器窗口，或在脚本管理器中选择「添加脚本」并粘贴文件内容，确认安装。
4. 打开智学网阅卷页面，脚本会自动挂载一个可折叠的面板；也可通过油猴菜单打开面板、设置、历史等。

> 若脚本管理器要求跨域权限，请放行 `@connect *`，否则无法调用你配置的大模型接口。

## 快速开始

1. 打开智学网阅卷页面，等待面板提示「已读取题号 xx」。
2. 点击面板中的 **设置**，完成以下必填项：
   - **批改上下文**：填写参考答案、评分标准、本方案满分；题目可留空但会影响精准度，建议填写，或用「评分标准生成」一键填入。
   - **接口与链路**：选择平台，填写 API Key 与模型名；点击「测试多模态」验证连通性。
3. 保存配置，返回面板。
4. 点击 **开始批改**，等待结果与分数回填。
5. 如需修正，直接在结果面板中编辑分数，再点击 **提交结果**。

## 使用说明

### 面板按钮

| 按钮 | 作用 |
| --- | --- |
| **开始批改** | 对当前题目读取作答图并调用模型评分，结果写入历史。 |
| **连续批阅** | 循环执行「批改 → 提交 → 等待换卷」；开始前会二次确认，运行中再次点击可停止。 |
| **提交结果** | 把分数填入智学网打分框并提交。默认弹出确认框；勾选旁边的「一次提交（免确认）」后跳过确认。 |
| **历史** | 查看过往批改记录，支持导出 CSV / HTML 与清空历史。 |
| **设置** | 打开配置面板。 |

### 设置面板

设置面板分为四个标签页：

1. **批改上下文**
   - 题目、参考答案、评分标准、满分。
   - 参考答案与评分标准为必填；满分需大于 0，且应与试卷实际分值一致。
   - 提示：题目留空时模型只能依据作答图与参考答案推断，批改精准度会下降。

2. **接口与链路**
   - 平台预设下拉框：选择内置平台或自定义；切换平台会自动恢复该平台此前填写的 API Key 与模型。
   - 接口地址、API Key、模型名：均可手动修改；点击「获取模型列表」可拉取接口支持的模型并选用。
   - **思考模式**（下拉菜单）：
     - `关闭`：注入关闭字段，省 Token、更快，适用于允许关闭思考的模型（字段名随平台不同）。
     - `low / high / max`：注入思考强度（如智谱 `thinking: {"type":"low"}`），用于**始终思考、不支持关闭**的模型（如智谱 `glm-5.3-flash`）。选关闭会对这类模型报 HTTP 400「该模型始终思考，不支持关闭思考；请使用 low、high 或 max」；发裸字符串则会报 JSON 反序列化 400，插件已自动使用对象结构。
     - `不干预`：不发送任何思考参数，使用模型默认设置。
     - 点击「测试当前思考模式是否生效」可验证；关闭模式检测响应中的推理字段与推理 token，强度模式确认参数被服务端接受。
   - 「管理自定义预设」：可新增、保存、删除自己的平台预设，并可填写思考控制字段名与 low/high/max 值映射（JSON）。
   - 「测试多模态」：发送一条最小请求验证接口可用。

3. **评分标准生成**
   - 选择学科与题型，填写满分（手动输入），输入题目与标准答案（文字或上传图片）。
   - 点击「生成评分标准」，结果在线可编辑，化学式、公式等符号可直接粘贴。
   - 点击「一键填入题目、参考答案、评分标准」会同时写入批改上下文的题目、参考答案、评分标准与满分。

4. **高级**
   - 导出 / 导入配置：备份或恢复配置、自定义预设、各平台 Key 与模型。
   - 重置默认、清空数据。

### 手动改分

批改完成后，结果区里的总分与各小题分数都是可编辑的数字框：

- 修改某个小题分数后，总分会自动按各小题求和更新。
- 直接修改总分时，各小题分数会按比例调整并做尾差修正。
- 提交时始终使用当前显示的（改后）分数，且不会污染缓存中的原始批改结果。

### 连续批阅

点击「连续批阅」并确认后，脚本会：

1. 批改当前试卷；
2. 静默提交分数；
3. 等待阅卷列表切换到下一份（通过试卷标识判断）；
4. 自动继续，直到点击停止、出现错误或超时未换卷。

连续批阅跳过所有确认弹窗，请确认评分标准准确后再开启。

### 历史与导出

- 历史记录包含：时间、题号、链路、模型、状态、得分/满分、小题分、评分依据、是否需复核、是否已提交。
- 可导出为带 BOM 的 CSV（Excel 可直接打开）或独立 HTML 文件。
- 历史条数默认上限 500，可在配置中调整。

## 支持的服务平台

内置预设包含：`自定义`、`opencode.ai`、`OpenAI 官方`、`Azure OpenAI`、`DeepSeek`、`硅基流动`、`Kimi / Moonshot`、`通义千问 / DashScope`、`智谱 GLM`、`火山方舟（Chat）`。

选择平台仅填充建议的接口地址、模型与协议参数，**你填写的 endpoint / model / apiKey 始终优先**。需要注意的是：

- 必须使用支持图片输入的多模态模型（如 `gpt-4o`、`qwen-vl-max`、`glm-4v-flash`、`doubao-seed` 系列等）。
- 接口需兼容 OpenAI Chat Completions 协议（`POST /chat/completions`）。
- API Key 仅保存在浏览器本地（通过 `GM_setValue`），不会上传到任何第三方服务器。

## 开发

项目为模块化源码，构建脚本按固定顺序把 `src/` 下的片段拼成单文件用户脚本，零第三方依赖。

```bash
# 构建
node build.mjs

# 运行测试
node tests/api-compat.test.mjs
```

- `src/`：功能源码（适配器、基础设施、核心流程、UI）。
- `build.mjs`：拼接与横幅生成。
- `dist/智阅批改助手.user.js`：可直接安装的产物。
- `tests/`：接线与行为一致性测试。

修改源码后需重新执行 `node build.mjs` 才会更新 `dist/` 中的脚本。

## 注意事项

- 请先在少量试卷上验证评分标准与模型效果，再用于大批量阅卷。
- 不同模型的打分尺度差异较大，建议固定一个模型并配套调整评分标准。
- 「思考模式」是否生效取决于服务端实现，可用内置测试按钮验证；智谱 glm-5 等始终思考的模型请用 low/high/max，不要用「关闭」。
- 连续批阅会自动提交分数，请谨慎开启。
